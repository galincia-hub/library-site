## [핵심 내용]
ComfyUI = 모델 불러오기·프롬프트·생성 상자(노드)를 선으로 잇는 워크플로 도구. 공식 데스크톱 앱 설치, 로컬에서만 쓰고 모르는 커스텀 노드는 설치 금지.

## [주요 주장]
- 사실(확인): GitHub 별 약 14만(Comfy-Org/ComfyUI 143,937, 10/30 조회), 사용자 400만+, 2026-04 $30M 투자·기업가치 $5억(Craft 주도, 누적 $47~48M), 1인 개발 프로젝트에서 출발.
- 부분 과장: "1,000대 넘게 해킹" → Censys/The Hacker News(2026-04)는 인터넷 노출 인스턴스 1,000+개가 공격 대상이라고 함. 실제 감염 수는 아님(스캔 1회 6,400개 중 취약 확인 214개). XMRig(모네로)·lolMiner(Conflux) 채굴 + Hysteria v2 프록시 봇넷.
- 미확인: "4GB 그래픽카드로 최신 영상 모델 구동"은 모델·양자화·속도에 따라 다름(검증 안 함).
