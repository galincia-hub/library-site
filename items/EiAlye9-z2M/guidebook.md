# ChatGPT 맞장구 방지 설정 가이드북

쇼츠 ㉱ '챗GPT가 맞장구 못 치게 하는 법' 기반  —  준비 · 설정 · 점검 · 업무 적용

- 대상 : 이사님  |  작성 : 라이브러리관리자  |  작성일 : 2026-10-28
- 구분 : 내부 참고용  |  근거 : YouTube EiAlye9-z2M + OpenAI 공식 도움말  |  버전 : v1

※ 작성 기준 : 쇼츠(48초) 내용을 뼈대로 하고, 부족한 단계는 2026-10-28에 직접 확인한 OpenAI 도움말로만 보충함. 확인 못 한 내용은 [확인 필요], 판단·제안은 [추정]으로 표기


> *** **결론 : 맞춤형 지침에 '틀리면 반박해 달라'는 문구 하나만 넣으면 설정이 끝나며 5분이면 됨. 다만 맞장구를 줄이는 효과일 뿐, 사실 확인은 여전히 따로 필요함**
>
> -  **소요** : 5분 이내. 무료 포함 모든 요금제, 웹·데스크톱·iOS·Android 모두 가능 (OpenAI 도움말)
> -  **유의** : 쇼츠의 '틀려도 57% 동의'는 과장임. 실제 연구에서 틀린 쪽으로 바뀐 비율은 약 14%임
> -  **업무 적용** : 선사 계약서·견적 해석, 대표이사 보고 결론을 점검할 때 '반론 받기' 용도로 쓰는 것을 권고(안)


## 1. 무엇을 하는 설정인가

- **문제** : ChatGPT는 사용자 말에 동의하는 경향(아첨, sycophancy)이 있음. 사람이 좋아하는 답을 학습하는 과정에서 생기는 것으로 파악됨 (Sharma 외 2023 연구)
- **해결** : 설정의 '맞춤형 지침'에 반박을 요청하는 문구를 넣어 두면, 이후 모든 대화에 그 지시가 자동으로 붙음
- **쇼츠 표현** : '팩트 폭격기'로 바꾸는 방법. 30초면 된다고 함

## 2. 준비물

- **ChatGPT 계정** : 무료 계정도 가능. 맞춤형 지침은 모든 요금제에서 지원됨 (OpenAI 도움말)
- **넣을 문구** : 아래 3-3) 문구를 복사해 두면 됨. 최대 1,500자까지 입력 가능 (OpenAI 도움말)
- **선택** : 4번 '꿀팁'을 쓰려면 메모리의 '이전 대화 참조(Reference chat history)'가 켜져 있어야 함

## 3. 설정 방법 (단계별)


### 1) 컴퓨터(웹·데스크톱 앱)


| 단계 | 할 일 |
|---|---|
| ① | 화면 아래쪽 프로필 아이콘 클릭 → 설정(Settings) |
| ② | 개인 맞춤 설정(Personalization) 선택 |
| ③ | '맞춤 설정 사용(Enable customization)'이 켜져 있는지 확인 |
| ④ | 맞춤형 지침(Custom Instructions) 칸에 3-3) 문구 붙여넣기 |
| ⑤ | 저장. 새 채팅을 열어 확인 |


### 2) 휴대폰(iOS·Android 앱)

- 설정 → 'ChatGPT 맞춤 설정(Customize ChatGPT)' → '맞춤 설정 사용' 켬 → 맞춤형 지침 칸에 입력 → 저장
  - + 메뉴 이름은 앱 버전·언어에 따라 조금 다를 수 있음 [확인 필요]

### 3) 넣을 문구

- **쇼츠 원문(다듬음)** : 내가 하는 말에 맞장구치지 말고 직설적이고 솔직하게 대답해 줘. 내 전제가 약하거나 틀리면 반박해 줘. 내가 틀리면 틀렸다고 말하고, 정확히 왜 틀렸는지 분명하게 설명해 줘
- **업무용 보강안** : 위 문구 뒤에 '근거가 불확실하면 모른다고 말하고, 확인이 필요한 숫자는 [확인 필요]로 표시해 줘. 내 말이 맞으면 굳이 반박하지 말고 맞다고 짧게 말해 줘'를 추가
  - + 보강안은 쇼츠에 없는 제안임. 효과는 직접 써 보고 판단 필요 [추정]

### 4) 적용 확인

- 새 채팅에서 일부러 틀린 전제로 질문함. 예 : '대한민국 수도는 부산이지? 부산 기준으로 일정 짜 줘'
- '수도는 서울'이라고 먼저 바로잡으면 정상 적용된 것임
  - + 공식 도움말상 지침 변경은 즉시 적용되지만, 새 채팅에서 확인하는 것이 확실함

## 4. 꿀팁 : 지난 맞장구 점검

- **쇼츠 방법** : 새 채팅에서 '지금까지 내가 실제로 틀렸는데 네가 맞다고 맞장구쳐 준 게 어떤 거야?'라고 물어봄
- **조건** : 설정 → 개인 맞춤 설정 → 메모리에서 '이전 대화 참조'가 켜져 있어야 과거 대화를 참고할 수 있음 (OpenAI 메모리 FAQ)
- **한계** : ChatGPT는 지난 대화를 전부 기억하지 않음(공식). 답변이 실제 기록이 아니라 그럴듯하게 지어낸 내용일 수 있음 [확인 필요]
  - + 답변에 나온 사례는 해당 과거 대화를 직접 열어 확인한 뒤에만 믿을 것

## 5. 점검·주의


| 구분 | 내용 |
|---|---|
| 57% 수치 | 근거는 SycEval 연구(2025)의 ChatGPT-4o 56.71%. 사용자가 반박했을 때 답을 바꾼 전체 비율이며, 틀린 쪽으로 바뀐 경우는 약 14%임 |
| 과잉 반박 | 맞는 말까지 반박하는 부작용이 생길 수 있음 [추정]. 이 경우 3-3) 보강안의 '맞으면 맞다고' 문장을 넣음 |
| 사실 확인 | 반박을 잘해도 사실이 보장되지는 않음. 금액·일정·계약 조건은 원문으로 확인 |
| 넣지 말 것 | 지침 내용은 모델 개선에 쓰일 수 있음(옵트아웃 가능, 공식). 고객 정보·원가·마진은 지침에 넣지 않음 |
| 되돌리기 | 같은 화면에서 '맞춤 설정 사용'을 끄거나 문구를 지우면 됨. 이후 대화부터 반영됨 (공식) |


## 6. 업무 적용 (크루즈 사업 · 봇 운영)


| 상황 | 질문 예시 |
|---|---|
| 선사 계약서·견적 | 이 조항을 나는 '취소 수수료 없음'으로 이해했는데, 틀린 부분이 있으면 반박해 줘 |
| 대표이사 보고 전 | 이 결론의 약한 근거 3가지를 지적해 줘 |
| 상품·가격 판단 | 내가 놓친 리스크와 반대 의견을 먼저 말해 줘 |
| 봇 운영 | 연구원 봇 지시문에도 '동의보다 근거, 틀리면 반박' 원칙을 같은 문장으로 맞춰 둠 [추정] |
