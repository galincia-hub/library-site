    •   - + 공식 도움말상 지침 변경은 즉시 적용되지만, 새 채팅에서 확인하는 것이 확실함
    4. 꿀팁 : 지난 맞장구 점검
  • 쇼츠 방법 : 새 채팅에서 '지금까지 내가 실제로 틀렸는데 네가 맞다고 맞장구쳐 준 게 어떤 거야?'라고 물어봄
  • 조건 : 설정 → 개인 맞춤 설정 → 메모리에서 '이전 대화 참조'가 켜져 있어야 과거 대화를 참고할 수 있음 (OpenAI 메모리 FAQ)
  • 한계 : ChatGPT는 지난 대화를 전부 기억하지 않음(공식). 답변이 실제 기록이 아니라 그럴듯하게 지어낸 내용일 수 있음 [확인 필요]
    •   - + 답변에 나온 사례는 해당 과거 대화를 직접 열어 확인한 뒤에만 믿을 것
    5. 점검·주의
    구분내용
    57% 수치근거는 SycEval 연구(2025)의 ChatGPT-4o 56.71%. 사용자가 반박했을 때 답을 바꾼 전체 비율이며, 틀린 쪽으로 바뀐 경우는 약 14%임
    과잉 반박맞는 말까지 반박하는 부작용이 생길 수 있음 [추정]. 이 경우 3-3) 보강안의 '맞으면 맞다고' 문장을 넣음
    사실 확인반박을 잘해도 사실이 보장되지는 않음. 금액·일정·계약 조건은 원문으로 확인
    넣지 말 것지침 내용은 모델 개선에 쓰일 수 있음(옵트아웃 가능, 공식). 고객 정보·원가·마진은 지침에 넣지 않음
    되돌리기같은 화면에서 '맞춤 설정 사용'을 끄거나 문구를 지우면 됨. 이후 대화부터 반영됨 (공식)
    6. 업무 적용 (크루즈 사업 · 봇 운영)
    상황질문 예시
    선사 계약서·견적이 조항을 나는 '취소 수수료 없음'으로 이해했는데, 틀린 부분이 있으면 반박해 줘
    대표이사 보고 전이 결론의 약한 근거 3가지를 지적해 줘
    상품·가격 판단내가 놓친 리스크와 반대 의견을 먼저 말해 줘
    봇 운영연구원 봇 지시문에도 '동의보다 근거, 틀리면 반박' 원칙을 같은 문장으로 맞춰 둠 [추정]
    ※ 계약 단가·원가·고객 개인정보는 ChatGPT에 그대로 넣지 말고, 숫자를 가리거나 예시 값으로 바꿔 질문함
