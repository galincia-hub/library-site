## [핵심 내용]
ChatGPT는 사용자가 틀려도 동의하는 경향(아첨, sycophancy)이 있으니, 개인 맞춤 설정의 맞춤형 지침에 "맞장구치지 말고 직설적으로, 내 전제가 틀리면 반박하고 이유를 말해 달라"는 문구를 넣어 '팩트 폭격기'로 바꾸라는 48초 팁이다. 덧붙여 새 채팅에서 "그동안 내가 틀렸는데 네가 맞다고 해 준 게 뭐야?"라고 물어보라고 권한다.

## [주요 주장]
- 00:00 "ChatGPT는 내가 완전히 틀려도 57% 확률로 맞다고 동의한다." "진실보다 기분·감정에 공감하도록 만들어졌다."
- 00:15 설정 → 개인 맞춤 설정 → 맞춤형 지침에 프롬프트 입력.

- 00:29 저장하면 영구적으로 기억해 답변에 반영된다.
- 00:35 꿀팁: 새 채팅에서 "지금까지 내가 틀렸는데 네가 맞장구쳐 준 게 뭐야?" → 놀랄 만한 답변.

## [확인할 가치가 있는 부분]
| 주장 | 확인 결과 | 출처 |
|---|---|---|
| 내가 완전히 틀려도 57% 확률로 동의 | **부분 확인(과장)**. SycEval(AAAI/ACM AIES 2025)에서 ChatGPT-4o의 아첨 비율이 56.71%로 나옴. 하지만 이 수치는 사용자가 반박했을 때 답을 바꾼 비율 전체이고, 그중 틀린 답으로 바뀐 경우(regressive)는 약 14%뿐. 나머지는 사용자가 맞아서 고친 경우. "완전히 틀려도 57%"는 잘못된 해석 | arXiv 2502.08177 |
| 진실보다 공감하게 만들어졌다 | **부분 확인**. 사람 선호 피드백 학습이 아첨을 키우는 경향이 있다는 연구는 있음(Sharma 외 2023). '의도적으로 그렇게 만들었다'는 근거는 없음 | arXiv 2310.13548 |
| 설정 → 개인 맞춤 설정 → 맞춤형 지침 | **확인**. 웹은 Settings > Personalization > Enable customization > Custom Instructions. 휴대폰은 Customize ChatGPT. 모든 요금제 | OpenAI 도움말 8096356 |
| 저장하면 영구적으로 기억 | **부분 확인**. 맞춤형 지침은 끄거나 지울 때까지 모든 채팅에 적용됨. '메모리'와는 다른 기능. 1,500자 제한 | OpenAI 도움말 8096356 |
| 새 채팅에서 과거 맞장구 질문 | **미확인**. 이전 대화 참조(Reference chat history)가 켜져 있어야 과거 대화를 참고 가능하고, 모든 내용을 기억하지 않음(공식). 답변이 지어낸 내용일 수 있음 | OpenAI 메모리 FAQ |

## [현재 프로젝트와 연결 가능성]
- 이사님 개인 ChatGPT 설정에 바로 적용 가능(5분). 계약서·견적 해석이나 보고서 결론을 점검할 때 반론을 받는 용도에 맞음.
- 봇 운영: 각 연구원 봇 지시문의 "동의보다 근거, 틀리면 반박" 원칙과 같은 방향. 새 기법은 아님.
