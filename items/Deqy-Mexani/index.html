클로드 구독으로 손님을 데려오는 하비

영업 에이전트 하비(Harvey)는 내가 정한 지역의 가게 홈페이지를 읽고, 가게마다 다른 영업 메일을 쓰고, 답장까지 읽으며 미팅 쪽으로 대화를 이어가요. 이미 내고 있는 클로드 구독으로 돌아가서 모델 사용료(API 요금)가 따로 들지 않는 오픈소스(MIT)예요.

・뭘 파는지와 원하는 손님을 알려 주면 가게를 찾아 점수를 매겨요
・가게 홈페이지에서 본 점을 짚어서 메일을 가게마다 따로 써요
・기본 설정은 메일마다 내 승인을 받은 뒤에 보내요

메일을 보낼 메일함과 발송 전용 도메인은 직접 준비해야 해요. 영업 메일 규정은 나라마다 달라서 보내는 사람이 책임지니, 쓰기 전에 확인하세요.

댓글에 손님이라고 남겨주시면 설치법 정리본 보내드릴게요.

[핵심 내용]

오픈소스 영업 에이전트 하비(Harvey, github.com/ethanplusai/harvey)를 소개하는 짧은 릴스다. 무엇을 파는지와 원하는 고객상을 알려 주면, 지정 지역의 가게를 찾아 홈페이지를 읽고 점수를 매긴다. 그리고 가게마다 본 내용을 짚어 서로 다른 콜드메일을 쓰고, 답장을 읽으며 미팅 쪽으로 대화를 이어 간다. 이미 내는 Claude 구독(Claude Code CLI)으로 돌아가서 별도 API 요금이 없다는 점을 가장 강조한다. 기본값은 메일마다 사용자 승인 후 발송이다. 발송 메일함과 전용 도메인은 직접 준비해야 하고, 영업 메일 법규 준수 책임은 발송자에게 있다.

[주요 주장]

  • 사실: MIT 오픈소스이고, Claude Pro/Max 구독(Claude Code)으로 모델을 호출하며 API 키가 필요 없다. 기본은 발송 전 승인, 전용 메일함·도메인은 직접 준비 (README로 확인)
  • 사실(과장 포함): "미팅이 잡힐 때까지 밤낮없이 대화" → 대화는 미팅 방향으로 이어 가지만, 캘린더 자동 예약은 README에서 아직 'Next'(미구현)로 분류됨
  • 의견: "스팸처럼 안 보인다", "제일 미친 건 추가 요금이 없다는 것"
  • 과장: "추가 요금 없음" → 소프트웨어는 무료지만 Claude 유료 구독, 메일함·도메인, 선택형 유료 리드 소스(DataForSEO·Serper, Instantly)는 따로 들고, 24시간 루프는 구독 사용량 한도에 걸릴 수 있음

[확인할 가치가 있는 부분]

  • 사용량 한도: Anthropic은 Pro/Max가 "통상적 개인 사용"을 전제한다고 밝힘. 상시 루프 운영이 약관·한도와 충돌하는지 (`max_daily_claude_percent` 설정 존재)
  • 리드 출처는 기본이 OpenStreetMap 무료이고, 이메일은 패턴 추정과 검증 서비스(Reoon/ZeroBounce)로 찾음 → 한국 가게·기업에 대한 실효성은 미지수
  • 한국 정보통신망법: 영리 목적 광고성 정보는 사전 수신동의 원칙이고, 이메일은 옵트아웃 기반이지만 표기 의무("(광고)" 표기 등)가 있음. 국내 발송 전 법무 확인 필요
  • 저장소 상태: Stars 약 1.6k, 2026-03 생성, 활발히 개발 중

[현재 프로젝트와 연결 가능성]

  • Cruise International 사업: 여행사·기업 인센티브 담당자 대상 B2B 리드 발굴·개인화 초안 작성에 응용할 수 있다. 단, 회사 메일은 회사 메일 계정 전용이고 무단 실발송은 금지라 '초안 생성 → 이사님 확인' 용도로만 적합. 별도 발송 도메인 신설은 정책·평판 리스크
  • AI 봇 운영/Orca: "구독 CLI로 루프 에이전트 운영" 아키텍처와 승인 게이트, SQLite 로그, 일일 한도 설계는 참고할 만함
  • 마케팅(Threads): 원문 자체가 '댓글 키워드 → DM' 퍼널 사례(댓글 774). 콘텐츠 포맷 참고 가치
  • 투자(국내주식·BTC): 관련 없음

[추가 연구 추천 여부]
