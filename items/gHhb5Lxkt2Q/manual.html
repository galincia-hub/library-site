GPT 아스트라 디자인 자동화 사용 매뉴얼

원본 영상 https://youtu.be/gHhb5Lxkt2Q · 채널 홍아린 AI · 작성일 2026-11-03 · 작성 라이브러리관리자

결론 ChatGPT 데스크톱 앱의 Work 탭에서 GPT-6 Astra로 랜딩 페이지를 먼저 만들고, 그 브랜드 톤을 같은 대화·브랜치로 이어 가면 쿠폰 페이지·카드뉴스·모션 PPT·캡컷 릴스까지 한 흐름으로 만들 수 있다. 다만 Astra 사용량 한도와 Figma 요금·권한은 [확인 필요]이며, 크루즈 사업에는 상품 1개 파일럿 1회로 먼저 검증하길 권한다.

단계별 사용법

순서: 랜딩 페이지 → 쿠폰 이벤트 → Figma 연결 → 카드뉴스 → 모션 PPT → 캡컷 편집. 영상의 가상 브랜드는 그래놀라 '모닝오트'이며, 랜딩 페이지의 브랜드 톤이 끝까지 레퍼런스가 된다. 아이디어 구상은 기본 모델, 제작만 Astra로 쓰면 사용량을 아낀다(15:29).

단계 1. 랜딩 페이지 01:47~ 모바일 확인 02:56 2차 수정 03:21

  1. ChatGPT 데스크톱 앱에서 Work 탭을 연다.
  2. 모델을 Astra로, 추론을 Medium으로 선택한다.
  3. 브랜드명과 타깃만 넣은 짧은 프롬프트를 보낸다 → 프롬프트 1.
  4. 몇 분 뒤 사이트 링크가 나오면 열어 본다.
  5. 모바일 확인(02:56): Chrome에서 아래 경로로 기기 화면으로 본다.
Chrome 우클릭 → 검사 → 기기 아이콘
  1. 영상에서 나온 문제 3가지: 글씨가 작음, 연한 회색, 밋밋한 색.
  2. 2차 요청(03:21): 레퍼런스 사이트 + 컬러·버튼·브랜딩 + 카피 + 숫자 지시. 레퍼런스는 복사 금지, 자사 특징을 추가한다 → 프롬프트 2.

수정은 "글씨 키워 줘"가 아니라 "11px 이상"처럼 숫자로 준다(03:34).

단계 2. 쿠폰 이벤트 페이지 04:13~

  1. 단계 1의 같은 대화창에서 한 줄로 요청한다 → 프롬프트 3.
  2. 영상 결과: 카드 뒤집기 쿠폰(5·10·15% 무작위, 1인 1회, 복사 버튼). 이 기능을 처음부터 확실히 넣고 싶으면 → 프롬프트 4(선택).
  3. '1인 1회'는 브라우저 저장 방식일 가능성이 높다 [추정]. 실제 판매 쿠폰으로 쓰기 전 검증한다.

단계 3. Figma 연결 06:18 선택 이유 07:12 플러그인 연결 07:40 모델 재선택

  1. 선택 이유(06:18): Canva는 화면 클릭 방식이라 무겁고, Figma는 레이어 단위 수정이 가능해 자동화에 유리하다.
  2. 07:12 ChatGPT 설정에서 Figma 플러그인을 설치한다.
설정 → 통합 → 플러그인 → Figma
  1. 설치 후 Figma 로그인·허용을 마치면 '연결됨'으로 표시된다.
  2. 07:40 새 대화를 열고 모델(Astra)을 다시 선택한다.

캔버스 쓰기는 Professional 이상 + 편집 권한이 필요하다. 베타 기간은 무료이나 이후 사용량 과금 예정이다.

  2. 채팅창에서 @Figma를 선택해 시안을 레이어로 분리한다 → 프롬프트 5. 드래프트 파일이라 맥락을 못 읽으면 → 프롬프트 6.

  1. 권한 오류가 나면 설정에서 컴퓨터 사용을 허용하고 진행한다 → 프롬프트 10.

단계 5. 모션 PPT 10:58~

  1. 랜딩 대화에서 브랜치(분기) 대화를 만든다.
  2. 추론을 Light로 낮춘다. PPT는 Light로 충분하다(15:29).
  3. 조건 3가지(애니메이션, 브랜드 컬러, 자막 공간)를 넣어 요청한다 → 프롬프트 11.
  4. 결과: .pptx 파일 + 슬라이드 메모.
  5. 애니메이션은 PowerPoint에서 직접 재생해 확인한다.

단계 6. 캡컷 편집 13:07~

  1. 캡컷 프로젝트에 소스(화면 녹화·카드뉴스·PPT 녹화·배경음악)만 넣어 둔다.
  2. 설정에서 컴퓨터 사용을 켜고 권한은 아래 항목으로 둔다. '전체 권한' 모드는 쓰지 않는다.
나 대신 승인
  1. 편집을 요청한다 → 프롬프트 12. 결과: 가로 영상 + 20초 9:16 릴스, 원본은 보존된다.
  2. "요청이 너무 많다" 같은 오류로 멈추면 → 프롬프트 13.
  3. 세로 릴스에 흰 여백이 생기면 → 프롬프트 14.

주의할 점

  • Astra 사용량: Plus($20/월)에서는 제한적이고 소모가 빠르다. 한도 안에서 가능한지 [확인 필요]. 아이디어는 기본 모델, 제작만 Astra, PPT는 추론 Light.
  • Figma 요금·권한: 캔버스 쓰기는 Professional 이상 + 편집 권한. Starter 불가. 베타 기간 무료, 이후 사용량 과금 예정.
  • 쿠폰 1인 1회: 브라우저 저장 방식일 가능성이 높다 [추정]. 실제 쿠폰으로 쓰기 전 검증.
  • 컴퓨터 사용: Intel Mac 미지원. macOS 화면 기록·손쉬운 사용 권한 필요. '전체 권한' 모드는 영상도 권고하지 않는다.
  • 수정은 숫자로: "11px 이상"처럼 구체적으로.
  • 이미지는 Figma로: 채팅창에 직접 붙이지 말고 Figma에 올려 연결하면 토큰 절약.
  • 애니메이션: PPT를 직접 재생해 확인.
  • 레퍼런스: 방향만 참고하고 그대로 베끼지 않는다.

조건은 세 가지야.
1) 제목·특징이 하나씩 차례로 나타나는 애니메이션을 넣어 줘.
