# 실제 사용 프롬프트 — GPT 아스트라 디자인 자동화 (홍아린 AI)

- 원본 영상: https://www.youtube.com/watch?v=gHhb5Lxkt2Q
- 환경: ChatGPT 데스크톱 앱 → Work 탭 → 모델 GPT-6 Astra (PPT는 추론 Light, 나머지는 Medium)
- [대괄호]는 바꿔 넣을 자리임. '영상 원문'은 영상 속 문장 그대로, '(영상 내용 기반 재구성)'은 영상에서 요지만 말한 것을 실제로 쓸 수 있게 다시 쓴 것임.

## 1. 랜딩 페이지 1차 생성
- 언제 : 새 브랜드·상품 소개 페이지의 첫 시안을 받을 때. Work 탭 · GPT-6 Astra · 추론 Medium
- 영상 위치 : 02:19 · (영상 내용 기반 재구성)

```text
[브랜드명] 브랜드 랜딩 페이지를 만들어 줘.
타깃 고객은 [타깃 고객]이야.
결과는 바로 열어 볼 수 있는 사이트 링크로 줘.
```

## 2. 랜딩 페이지 2차 수정 (레퍼런스 + 숫자 지시)
- 언제 : 1차 결과의 글씨 크기·색 대비·톤을 고칠 때. 같은 대화창에서
- 영상 위치 : 03:21 · (영상 내용 기반 재구성)

```text
[레퍼런스 사이트 URL] 사이트를 참고해서 컬러, 버튼, 브랜딩을 바꾸고 카피라이팅도 같이 고쳐 줘.
레퍼런스는 방향만 참고하고 그대로 베끼지 마. 우리 브랜드 특징([특징 1], [특징 2], [특징 3])은 꼭 살려 줘.
본문 글씨는 [11]px 이상으로 키우고, 배경에 묻히는 연한 회색 글씨는 진한 색으로 바꿔 줘.
```

## 4. 쿠폰 조건 명시 (선택)
- 언제 : 영상에서는 AI가 알아서 넣은 기능(무작위 할인율·1회 제한·복사 버튼)을 처음부터 확실히 넣고 싶을 때
- 영상 위치 : 05:15 · (영상 내용 기반 재구성)

```text
쿠폰 카드 [3]장 중 하나를 고르면 카드가 뒤집히면서 [5%·10%·15%] 중 하나가 무작위로 나오게 해 줘.
한 사람은 한 번만 고를 수 있게 하고, 쿠폰 코드 복사 버튼과 [상품 보러 가기] 버튼([링크])을 붙여 줘.
```

## 11. 모션 PPT 생성
- 언제 : 랜딩 대화에서 브랜치(분기)한 새 대화에서. 추론 Light로 낮춰서
- 영상 위치 : 11:21 · (영상 내용 기반 재구성)

```text
지금까지 만든 [브랜드명] 브랜드로 [브랜드 소개 영상]에 넣을 설명용 PPT를 파워포인트(.pptx) 파일로 만들어 줘.
조건은 세 가지야.
1) 제목·특징이 하나씩 차례로 나타나는 애니메이션을 넣어 줘.
2) 랜딩 페이지의 브랜드 컬러와 제품 사진을 그대로 써 줘.
3) 영상에 넣을 거라 화면 아래 자막 자리를 비워 줘.
슬라이드 메모에는 브랜드 컬러 코드, 자막 공간 위치, 이미지 출처를 적어 줘.
```
