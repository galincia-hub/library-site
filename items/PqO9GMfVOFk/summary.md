# 유튜브 잘하는 사람들은 지금 클로드로 이렇게 작업합니다 (OPUS5.5)

## [핵심 내용]
크리에이터 커뮤니티 운영자가 Claude Opus 5.5 + Claude Code로 B롤(자료화면), 효과음, 컷 편집, 쇼츠 분할까지 거의 자동으로 처리한 경험을 공유. 핵심 메시지는 "AI로 영상을 찍어내자"가 아니라 "내 원본(얼굴·페르소나)을 유지하면서 발행량을 늘리는 데 AI를 쓰고, 아낀 시간은 기획(누구를 어떻게 도울지)에 쓰라"는 것. 구체적인 프롬프트·코드는 영상 밖(PDF·GitHub)으로 미뤄져 있어 방법론 세부는 얕음.

## [주요 주장]
- 사실(화자 경험·인용, 미검증):
  - 에이피알(메디큐브)이 북미에서 30일 동안 영상 12만 5천 개를 발행했다는 기사 인용(AI 사용 여부와는 무관하다고 화자가 단서를 붙임).
  - 이번 롱폼 1편 작업 규모: B롤 59개, 효과음 120개 이상, 컷 편집 140개. 9/14 시작해 약 13일간 반복 피드백. 롱폼 1편 → 쇼츠 7개 자동 분할(쇼츠는 상단 B롤 40%·하단 인물 60% 스플릿, 자막 위치 연동).
  - Opus 5.5 이후 토큰 소모가 줄어 Claude Code에 말로 수정 지시하는 쪽이 Premiere XML 후작업보다 빨라짐. 쇼츠는 Premiere·After Effects 없이 완성, 롱폼만 일부 수정 중.
  - 권장 요금제: Pro는 부족하고 Max(월 약 $100) 추천. 작업창 5개 병렬, 맥 음성입력(Control 두 번)으로 지시.
  - 외주 비용 비교(화자 추정): 그래픽 들어간 롱폼 편당 약 30만 원, 쇼츠 편당 약 5만 원, B롤 많은 20분 영상 외주 70~80만 원.
  - B롤 6유형: 숫자, 목록, 비교, 단계, 출처, 사례.
- 의견:
  - 콘텐츠 공급이 AI로 폭증하면서 '원본 인간'이 귀해짐. 원본이 되는 가장 쉬운 길은 ① 얼굴 공개 ② 명확한 페르소나(누구에게 어떤 관점으로 말할지).
  - 실력은 천천히 늘지만 운은 시도 횟수에 비례하므로(모부신) 주 1회 롱폼으로는 부족하고 발행 빈도를 올려야 함(인지 → 호감 → 질문 → 구매 → 옹호 퍼널).
  - 유튜브는 점점 사업보다 '자영업'에 가까워짐. 내가 빠지면 대체되는 시스템형 채널은 시간이 갈수록 흐려지고, 내 이름을 걸어야 생존함.
  - "AI 딸깍"으로 만든 결과물은 누군가의 하위 호환일 뿐임. AI는 내 원본 영상을 쪼개 발행량을 늘리는 데 써야 함.
  - 미감은 학습 가능: 핀터레스트 무드보드 링크를 Claude에 주고 톤(예: 어두운 바탕·낮은 채도·따뜻한 조명·포인트색 1개)을 추출해 모든 시각물에 일관 적용하고, 브랜드 컬러를 고정.
  - 사람들은 말보다 출처를 믿음. 주장 옆에 시각 자료가 있으면 신뢰가 오름(연구 인용, 출처 미제시).
  - 남는 시간은 기획에 써야 함: 콘텐츠·BM·브랜딩 기획을 한 줄 "누구를 어떻게 도울 것인가"로 정리(세스 고딘). 가치 = (원하는 결과 × 달성 확신) ÷ (시간 × 수고)(호르모지).
- 전망:
  - 영상 제작 허들이 사라져 유튜브는 '아이디어·기획 싸움'이 됨.
  - 크리에이터는 AI로 대체될 '사본'과 대체 불가한 '원본'으로 갈림.
- 가설:
  - 발행량을 늘리면(같은 실력이라도) 터지는 영상이 나올 확률이 오름. 운과 시도 횟수 논리이며 채널별 데이터는 제시되지 않음.

## [확인할 가치가 있는 부분]
- 실제 B롤 자동화 프롬프트·워크플로는 영상에서 개략만 설명되고 "PDF·GitHub 공개 예정"으로 미뤄짐. 링크·저장소 실존 여부 미확인.
- 메디큐브 '30일 12만 5천 개'는 기사 출처 미제시. 크리에이터·어필리에이트 UGC 합계일 가능성이 높아 단일 브랜드 제작물로 해석하면 안 됨.
- 'Opus 5.5', 'Max 월 $100', 토큰 효율 개선 체감은 화자 개인 사용 경험. 요금·한도는 Anthropic 공식 페이지 확인 필요.
- 사진·그림 기억 효과, '사진만 붙여도 참이라고 믿는 비율 상승' 같은 연구 인용은 논문명이 없음(진실성 착각 truthiness 연구로 추정).
- 자막 오인식(추정): "송기령/송계령/송기랑"=송길영(신간명 "수고 인류"는 불확실), "마이클 무브신"=마이클 모부신(『운과 실력의 성공방정식』), "에던 그랜트"=애덤 그랜트(『오리지널스』), "필리코틀러"=필립 코틀러, "세스고딘/데스고 린치핀"=세스 고딘 『린치핀』, "알렉스 홀모지"=알렉스 호르모지, "삐로/비롤/B로"=B-roll, "AP 회사"=에이피알(APR), "영인리치"=영앤리치, "빈도스"=빈도수, "명상"=영상, "AR 딸깍"=AI 딸깍. 미확인: "이렉타르 컴퍼니", "플라야", "페이블 5.1", 첫 문장 "허이".
- 홍보성 내용 제외: 팀비블 커뮤니티·단톡방·컨설팅 안내, PDF 배포 유도, 다른 영상(비즈카페 등) 시청 권유.

## [현재 프로젝트와 연결 가능성]
- Threads 마케팅: '원본(얼굴·페르소나) + 발행량' 원칙과 B롤 6유형(숫자·목록·비교·단계·출처·사례)은 Threads 카드뉴스나 캐러셀 포맷 설계에 바로 응용 가능. "누구를 어떻게 도울 것인가" 한 줄 정의는 Cruise International 콘텐츠 기획 기준으로 쓸 수 있음.
- AI 봇/도구: Claude Code로 롱폼 → 쇼츠 분할, 무드보드 → 디자인 토큰 추출, 자동 B롤 생성 파이프라인은 사이드 프로젝트·콘텐츠 자동화 도구 후보. 공개 예정 GitHub 저장소를 확인할 가치 있음.
- 크루즈 사업: 크루즈 상품 영상(기항지 숫자·비교·일정 단계)을 B롤 템플릿으로 자동화하는 아이디어. 메디큐브식 대량 UGC 전략은 여행 어필리에이트에 참고.
- 투자: 연관 없음.
