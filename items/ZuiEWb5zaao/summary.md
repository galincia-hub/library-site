## [핵심 내용]

## [주요 주장]
- 사실(확인): 2024년 5월 출시, 고교 친구 Henry Langmack과 공동창업, 17세에 시작(현재 19세) — TechCrunch·Inc.·Latka.

- 사실(확인): 18곳 지원·15곳 불합격(2025.4 X 게시, 4.0 GPA·ACT 34). 조회수는 TechCrunch 2,200만+, FOX5/본인 2,800만 → "2천만 넘게" 맞음.
- 사실(확인): 다운로드 1,500만+ — TechCrunch(MFP 제공).

- 사실(확인): 16세에 직접 만든 게임 웹사이트 매각, 7세 코딩 시작(FOX5 등).
- 부분 정확: "작은 틱톡 크리에이터 수백 명" — 약 250명 월 리테이너, 틱톡+인스타그램. 단 팔로워 최소 ~5만 기준이라 '초소형'보다는 결속력 높은 니치 크리에이터. 인스타·페이스북 퍼포먼스 광고도 병행(Inc.)→ "큰 광고 대신"은 단순화.
- 부분 정확: "앱은 늦게 보여줄 것" 규칙 — 실제로는 '평소 콘텐츠 포맷 유지 + 앱 등장 시점 테스트'. 초기엔 늦게 넣다가 점점 앞당겨 20~30초가 최적(Jake Castillo), 다른 담당자는 "15초 안"을 규칙으로 언급. 고정 규칙이 아님.
- 미확인/생략: 창업자는 2026년 MFP를 떠나 새 스타트업 'Persona' 준비(netinfluencer, TechCrunch Disrupt 2026) — 영상엔 없음.

## 기술적인 방법
1. 앱 구조(사진→칼로리): 사진 촬영 → 서버에서 범용 비전 LLM API 호출(창업자: "ChatGPT 같은 API, 자체 모델 학습 안 함") → 프롬프트로 음식 종류·추정 중량·칼로리·탄단지를 구조화(JSON) 출력 → 영양 DB와 대조(인수 후 MFP DB 2천만 식품·6.85만 브랜드·380+ 체인 연동) → 사용자가 양 보정. 차별화는 모델이 아니라 프롬프트·UX(결과를 한눈에, 화면에 앱 이름 크게 = 영상에 찍혔을 때 2초 안에 이해).
2. 수익화: 온보딩 후 페이월(Superwall로 수백 개 A/B 테스트), 첫 세션 전환 20~25%, 구독형.
3. UGC 크리에이터 배포 플레이북: ① 팔로워 수보다 조회수·참여도·충성 커뮤니티로 선발(최소 ~5만) ② 대본 없이 평소 포맷('하루 식단' 등)에 앱의 핵심 장면(사진 찍어 칼로리 뜨는 순간)만 삽입 ③ 앱 등장 시점을 테스트해 최적점 찾기(Cal AI 20~30초 / 15초 이내) ④ 영상당 고정가 대신 조회수 보장·영상 묶음 계약으로 CPM 관리 ⑤ ~250명 월 리테이너, 팀 절반이 크리에이터 관리 ⑥ 첫 테스트: $2,000 스토리 1건 → 이틀 1,000 다운로드·유료 100명. 월매출 $3만→6개월 만에 $100만.
