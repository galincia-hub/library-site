## [핵심 내용]
글을 생성하지 않고 '질문 + 선택지'를 주면 선택지별 확률(또는 점수, 예/아니오)만 돌려주는 새로운 유형의 AI인 TypeSafe의 Jev를 소개하는 영상이다. 공개 일주일 만에 나온 활용 사례 7개를 보여 준다.
- 볼거리 데모 4개:
  - 브라우저 에이전트 jev-ultrafast: 구글 항공권 검색을 7.1초에 처리.
  - 시뮬레이터 드론: 장애물 코스 약 47초 통과.
  - 마리오: 에뮬레이터 메모리 숫자를 입력으로 받아 동작 7개 중 하나를 고름.
  - 코인 모의매매: 호가창을 보고 블록마다 살지 팔지 판단.
- 개발자용 도구 3개:
  - Claude Code 대화 압축 플러그인: 요약을 새로 쓰지 않고, 도구 기록마다 남길지 말지를 예/아니오로 판단.
  - Codex 모델 라우터: 일이 어느 등급 모델이면 충분한지 판단.
  - Jev Review: 코드 리뷰 위험도 점수.

이어서 화자가 직접 쓰는 법을 보여 준다. 가입 후 API 키를 받고, 키를 파일로 분리해 둔 다음, Claude Code나 Codex에 공식 문서를 주며 Jev 스킬이나 MCP 설치를 요청한다. 작업을 맡길 때 "Jev를 쓰면 효과적인 부분은 Jev를 써 줘" 한 줄을 덧붙이면 된다. 사례로 자기 사이트 SEO 점검을 보여 주는데, 247페이지를 읽고 글을 읽어야 판단할 수 있는 항목만 Jev에 1,507번 물었으며 비용은 60원 미만이었다. 결론은 Jev가 비용과 출력 형식 불안정이라는 두 문제를 풀어 프로그램에 AI 판단을 넣기 쉽게 만든다는 것이다. 단, Claude나 Codex를 대체하지는 않고 보완한다고 본다.

## [주요 주장]
- 사실(영상 언급, 일부 웹 확인):
  - Jev는 텍스트를 출력하지 않고 선택지마다 확률을 매긴다. 입력 토큰에만 과금하고 출력은 무료다. 공식 가격은 입력 100만 토큰당 $0.042이며, 웹으로 확인했다.
  - browser-use의 jev-ultrafast는 화면 요소에 번호를 붙이면 Jev가 클릭·입력·스크롤 중 하나와 대상을 고르고, 입력할 글자만 작은 언어 모델이 쓴다. 공개 일주일 남짓 만에 GitHub 별 19,000개를 넘겼다(웹 확인: 2026-09-16 생성, 2026-10-08 기준 약 22.4k).
  - 대화 압축 도구, Codex 라우터, Jev Review는 개인 개발자들의 프로젝트다. 라우터 작성자는 과거 기록으로 시뮬레이션해 보니 사용량이 약 60% 줄었다고 한다(자기 보고).
  - 공식 문서 기준 Jev는 영어 중심으로 학습돼 한국어 등은 정확도가 떨어진다. 계산과 개수 세기에 약하고, 확률이 높다고 정답이라는 보장도 없다.
  - 초기 가입 계정에는 $5가 지급됐지만, 촬영 시점에는 초대 전용과 대기 명단으로 바뀌었다.
- 의견:
  - 대량 데이터 판단에서 기존 LLM은 느리고, 일부를 확인하지 않고도 확인했다고 답하는 일이 있다. Jev는 잘게 나눠 하나씩 물어도 빠르고 싸서 빠짐없이 판단할 수 있다.
  - 출력이 정해진 선택지의 확률이라 할루시네이션이 줄고, 프로그램에서 처리하기 쉽다.
  - 최종 결정은 코드나 사람이 하고, Jev는 판단 보조로 쓰는 게 좋다.
  - API 키는 터미널에 붙여 넣지 말고 실행 폴더의 파일에 넣은 뒤 그 위치만 알려 주며, 그 파일이 깃허브에 올라가지 않게 주의한다.
- 전망:
  - Jev와 비슷한 '판단 전용 AI'가 많이 나오고 활용 사례도 늘어날 것이다. 새로운 타입의 AI가 Jev에서 시작됐다.
  - Claude나 Codex를 대체하지 않고 공존한다(Jev 대표도 Claude Code를 계속 쓰겠다고 했다고 함).
- 가설(근거 약함):
  - TypeSafe는 기존 LLM보다 최대 200배 빠르고 400배 싸다고 발표했다. 개발사 주장이고 비교 조건은 불명확하다. 입력 단가만 보면 Claude Fable 5.1 입력 단가($10/M)의 약 1/238 수준이다.
  - Codex 라우터의 '사용량 약 60% 절감'은 작성자 시뮬레이션일 뿐 검증되지 않았다.

## [확인할 가치가 있는 부분]
- 웹 확인(2026-10-09): 공식 문서(docs.typesafe.ai)상 현재 모델은 jev-1.13.0이고, 입력 $0.042/M, 출력 무료다. 한도는 초당 10만 토큰·80요청이며, 1요청 64k 토큰까지, 텍스트 입력만 가능하다(이미지·음성 불가). Vercel AI Gateway에도 같은 가격으로 올라와 있다.
- 주의: 'jevtypesafeai.com'처럼 공식처럼 보이는 별도 도메인이 $0.25~0.42/M 선불 팩을 판매하고 있다. 공식(typesafe.ai)과 가격이 다르므로 가입·결제는 공식 도메인에서만 해야 한다. 재판매나 사칭 사이트일 가능성이 있다.
- 경쟁: Cloudflare가 2026-10-01 같은 요청 형식의 판단 모델 Clef($0.24/M)와 Clef-flash($0.09/M)를 출시했다고 한다(외부 글 기준, 미검증). 판단 전용 모델 시장이 바로 경쟁 구도로 들어간 셈이다.
- 한국어 정확도가 떨어진다는 공식 경고: 이사님 용도(한국어 콘텐츠, 고객 문의)라면 state를 영어로 바꾸거나 한국어로 직접 평가해 봐야 한다.
- '60원 미만', '1,507회', '247페이지'는 화자 개인 사이트 사례라 재현성은 알 수 없다. 다만 단가를 감안하면 규모상 그럴듯하다.
- 자막 오인식(추정): "재부/제부/제프/제브/재은/제로"=Jev, "타입 세이프"=TypeSafe, "추리"=취리히, "제부 울트라 패스트"=jev-ultrafast, "패스트 제부 컨팩션"=Fast Jev Compaction, "제 코덱스 라우토"=Jev Codex Router, "입력만 토큰의 0.04 사이 달러"=입력 100만 토큰당 $0.04, "귀동"=기둥, "먹겨서"=매겨서.
- 홍보성 내용 제외: 좋아요·구독·알림 요청, 설명란 링크 안내, 쇼츠 언급.

## [현재 프로젝트와 연결 가능성]
- AI 봇/도구(핵심): 이사님 봇들에 '싼 판단 레이어'로 바로 붙일 수 있다.
  - 유튜브 라이브러리: 라우팅 번호(0~4) 분류, Research Level 초안, 홍보 구간 감지를 Jev의 choice/score 질문으로 처리하고, 요약 작성만 LLM에 맡기는 식이다.
  - 그 밖에 Threads 댓글과 DM 분류(문의, 스팸, 리드), 크루즈 고객 문의 라우팅(예약, 환불, 일정, 가격), 뉴스나 공시의 관련도 점수, 어제 저장한 @seb.ai '6봇' 구조의 Decision·Risk 판단(BUY/WAIT/SKIP)에 그대로 들어맞는다.
  - Codex 라우터 아이디어(작업 난이도별 모델 선택)는 봇 운영 비용 절감에 참고할 만하다.
- 크루즈 사업: 대량 상품 데이터(기항지, 일정, 가격 페이지) 품질 점검이나 SEO 점검을 '페이지마다 판단'으로 빠짐없이 돌리는 사례가 Cruise International 사이트·블로그 점검에 그대로 응용된다.
- Threads 마케팅: 게시물 후보의 훅 점수나 카테고리 분류에 쓸 수 있다. 다만 한국어 정확도 검증이 먼저다.
- 투자: 직접 연관은 적다. 코인 모의매매 데모는 장난감 수준이다.
